# Contexto 002

`docs/002` é a **fonte canônica de contexto** para IA. As 11 fontes de
`docs/001` estão aqui integralmente, convertidas para Markdown e fatiadas em
arquivos únicos — sem cópia completa duplicada dentro de `002`.

Comece aqui:

- [Mapa mestre de fatiamento](./00-mapa-de-fatiamento.md)
- [llms.txt](./llms.txt) — índice simples para exportar/embarcar em outras IAs
- [PROD-TEN-001 — SaaS multitenant mentor/mentorados](./decisoes/01-saas-multitenant-mentor-mentorados.md)

Cada fonte tem um `00-indice.md` com a quantidade de partes e os links.
Concatenando as partes de uma fonte, obtém-se a transcrição integral.

`docs/001` continua intacto como acervo original para auditoria. Em conflito
metodológico, anexos canônicos (`ANX-*`) prevalecem sobre PDF e `.docx`.
